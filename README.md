# man-tra

Mini-game prototype for learning mantras (syllable sequence training). Built as a reusable module for a bigger React Native app, with a web demo powered by React Native Web.

## Live demos

- Demo: https://mantra-game.netlify.app
- Adapted solution: https://namo-app.netlify.app

## What it does

- Shows a mantra as a syllable sequence with the current position highlighted
- Lets you select the next correct syllable from a board
- Tracks completed cycles and persists progress (AsyncStorage)

## Tech

React, React Native Web, AsyncStorage, Webpack

## Local development

```bash
npm install
npm start
```
